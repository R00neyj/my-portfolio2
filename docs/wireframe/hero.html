    • 반투명 젤리 재질 + 림 라이트. 천천히 떠다니고, 포인터를 따라 몸을 돌리고, 가끔 눈을 깜빡입니다

    • 장식이라 aria-hidden이고 클릭을 막지 않습니다. 동작 줄이기 설정이면 멈춘 화면 한 장만 그리고, 클릭해도 튀어오르지 않고 웃기만 합니다
    • 캔버스 배경색이 --color-bg와 같아서 테마를 바꾸면 함께 바뀝니다

  • 헤더 높이: 56px(모바일) / 64px(768px 이상)
  • 좌우 여백: 16px / 32px(768px 이상) / 48px(1024px 이상)
  • 제목·소개는 왼쪽 정렬, 스크롤 표시만 가운데 정렬
  • 미리보기 틀 안에서 크기가 바뀌도록 vw 대신 cqw(틀 너비의 1%)를 씁니다. 실제 구현에서는 vw, 100svh로 바꿉니다
