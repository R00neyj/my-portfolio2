Projects 섹션 — 분류 칩 와이어프레임

칩을 눌러 보세요. 실제 사이트에 넣기 전, 배치와 동작만 확인하는 회색 상자 그림입니다.

Projects

① 분류 칩 — 한 번에 하나만 선택
② 결과 개수 안내 (화면 읽기 프로그램에도 읽힘)

③ 카드 목록 — 선택한 분류만 보임 / 카드에 분류 배지

    동작 정리

    1. 처음엔 전체가 선택돼 모든 작업물이 보입니다.
    2. 칩 옆 숫자는 그 분류에 속한 작업물 개수입니다. 개수가 0인 분류는 칩을 만들지 않습니다.
    3. 칩은 <button aria-pressed>라서 키보드(Tab → Enter/Space)로도 고를 수 있습니다.
    4. 디자인 작업물은 링크 대신 이미지가 있으므로 카드에 썸네일만 크게 보이고 “소스 코드” 링크는 숨깁니다.
    5. 라이브러리 설치 없이 React useState 하나로 거릅니다.

    배열 데이터에 추가할 항목 (src/data/types.ts)

  slug: string
  category: ProjectCategory   // ← 새로 추가
